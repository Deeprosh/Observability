# What is "Observability"? Why do we need it?  
**If you have observability in place, you can understand the state of internal system(application,disk or cpu or memory utilization, number of https requests passed, infrastructure required by application and networking, etc.,).. It will also helps you understand why the system is in that state if any failure occurs.It also help us to fix this issue.**
## 3 pillars of Observability:
- Metrics
- Logs
- Traces
  
*`Metrics:`Its responsible for understanding 'what' is the state of the system.*  
*`Logs:`Its responsible for understanding 'why' is the system in this state.*  
*`Traces:`Its responsible for understanding 'How' to fix the state.*
